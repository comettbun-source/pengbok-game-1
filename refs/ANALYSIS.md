## 영상 2 — URP 물 강좌 (9분, 640×360)

Unity URP **Boat Attack** 데모의 물 셰이더 설명 영상 (한국어 유튜버). 화면에 빨간 펜으로 요소를 짚어줌:

- **wave** — 큰 파도(여러 개 겹친 사인/거스너 파), 수면 전체가 천천히 움직임
- **reflection** — 하늘·바위 반사 (Planar Reflection)
- **refraction** — 물 밑 바닥이 일렁이며 왜곡
- **caustics** — 얕은 바닥의 밝은 그물 무늬
- **sky blue / fresnel** — 멀리 볼수록(눕게 볼수록) 하늘색 반사가 강해짐
- **subsurface scattering** — 파도 마루가 빛을 받아 청록색으로 비침
- **shore / foam** — 해안선 거품, 얕은 곳이 밝은 청록
- 후반: 패키지 설치, `WaterSystemFeature`(RenderFeature) / `Water.cs` 코드, 깊이 텍스처로 얕은 곳 색 처리

→ 우리 게임(흑·백·크림 실루엣) 기준으로 쓸 만한 것: **fresnel(먼 곳일수록 밝게)**, **깊이에 따른 색(이미 DEPTH 있음)**, **해안 거품 = 현재 SHORE_WASH**. 반사/굴절/커스틱은 색이 많아 Sky풍 단순화와 충돌 → 옅은 선으로만.

## 물 엔진 제안 (확인 후 진행)

1. **높이장 파동 그리드** (저해상도 예: 96×96, 펭귄 주변 ≈ 16×16 캐릭터 키 영역, 펭귄 따라 이동)
   - 매 프레임 `h' = (이웃 평균 × 2 − h_prev) × 감쇠` (2D 파동 방정식)
   - 펭귄/빙하가 누르는 만큼 물을 밀어냄 → 입수 시 ②움푹 링 ③물기둥 ④동심원이 자동으로 생김
   - 빙하·해안이 벽 역할 → ⑥반사파 자동
2. 그리기: 높이 기울기로 **밝은 선/어두운 선**만 (현재 ripple 선 스타일 유지), 커스틱 대신 옅은 크림 선
3. 입수 연출 값 (새 블록 `WATER_SIM` 제안): 그리드 크기, 파동 속도(4–6/s), 감쇠, 입수 세기, 물기둥 높이(0.3–0.5)/시간(0.12s)
4. 기존 `ripple` 링은 끄고 비교할 수 있게 `?water=sim` 토글

※ 아직 게임에는 아무것도 적용하지 않았음.

## 적용 결과 — 물 엔진 1차 (`water.js`, `config.js` 의 `WATER_SIM`)

참고: Evan Wallace WebGL Water(영상 1의 원본 데모), Matthias Müller Height Field Water(부피 보존 방식), 얕은 물 파동(수심에 따른 파속).

| 영상에서 본 것 | 엔진에서 만들어지는 방식 |
|---|---|
| ② 접촉 시 움푹 링 | 몸이 잠긴 만큼 그 칸의 수면을 내리고, 같은 부피를 둘레 고리에 올림 (부피 합 0) |
| ③ 가운데 물기둥 | 꺼진 자리로 물이 되몰려 솟음 (파동 방정식 결과, 따로 연출 없음) |
| ④ 동심원, 간격이 벌어짐 | 파동 전파 + 분산 항(짧은 파장이 느림) |
| ⑤⑥ 떠오름·출렁임 | 기존 부력 스프링(`PHYSICS.waterEntry`) + 주변 수면 높이를 타고 오르내림 |
| 벽 반사파 | 빙하 안쪽 칸은 막힌 칸 → 물결이 되튕김 |
| 해안 | 수심이 얕아질수록 파속 감소 + 흡수 → 스러짐 |

검증(node): 낙하 입수 시 중심 수면 −0.105 → 0.17초 뒤 +0.088(물기둥) → 링 전파, 격자 전체 부피 합 0 유지, 발산 없음.
아직 그대로 둔 값: `PHYSICS.waterEntry`(주기 1.0, 감쇠 0.25) — 영상 기준(0.6~0.8s, 1~2회)으로 바꿀지는 확인 후.

## 영상 3 — 해안 물 움직임 (Fluid Flux, 24초) → 물 엔진 2차 (해안)

프레임: `refs/video/shore/` (o_ 전체, b_ 해변 0~5초, c_ 얕은 물 걷기·헤엄).

| 영상에서 본 것 | 엔진 (`WATER_SIM.shore`) |
|---|---|
| 파도가 바다에서 줄지어 밀려옴, 해안을 따라 세기가 다름 | `wave` — 물가 밖에서 마루를 만들어 해안으로 보냄 (`ampVar`, `varLength`) |
| 얕아질수록 느려지고 높아지다 부서짐 | 수심에 따른 파속(발산형 파동식) + `breakSpeed` 넘으면 거품 |
| 얇은 물막이 모래 위로 올라갔다 빠짐 (끝선이 혀 모양) | 뭍 칸은 땅 높이보다 수면이 높을 때만 젖음. `beachSlope`, `bumpy`, `drain` |
| 올라오는 앞쪽에 흰 거품, 빠지면서 성긴 레이스로 남음 | 거품 필드: 올라올 때만 생기고 `foamLife` 로 사라짐, 무늬 `render.lace` |
| 물이 지나간 모래는 어둡게 젖었다 마름 | 젖음 필드 `dryTime` |
| 얕은 물을 걸으면 거품 자국 | 얕은 곳에서 수면이 빨리 움직이면 거품 (같은 규칙) |

검증(node, 1차원 해변): 파도 높이 0.09 → 물막이 물가 안쪽 약 1.4까지 올라갔다 1초쯤 뒤 빠짐, 발산 없음.
